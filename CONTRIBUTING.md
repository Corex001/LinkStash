# Contributing to LinkStash

Thanks for wanting to help!

## Getting started

1. Fork the repository and clone your fork.
2. Follow the "Run the backend" steps in README.md.
3. Create a branch: `git checkout -b my-change`
4. Make your change and add a test if you can.
5. Open a pull request and explain what you changed and why.

## Ground rules

- Keep changes small and focused.
- Never commit secrets, passwords or database files.
- Be kind and respectful to everyone.
